# GAME-MANIA Frontend (Storefront)

Next.js 15 App Router customer website.

## Dev

```powershell
npm install
npm run dev
```

http://localhost:3000

## Notes

- Full page set lands in Phases 3–7 (see docs/architecture/roadmap.md)
- Design tokens in `src/app/globals.css`
- API helper: `src/lib/api.ts`
- Cart client state: Zustand (`src/stores/cart-store.ts`)

## Env

Copy `.env.example` → `.env.local`
