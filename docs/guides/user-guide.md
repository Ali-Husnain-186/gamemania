# User Guide

## Shopping

1. Browse **Shop** or **Categories**
2. Open a product → **Add to cart**
3. Optional: save to **Wishlist**
4. Open **Cart** → apply coupon / store credit / points
5. **Checkout** → choose Stripe or PayPal
6. Track under **Account → Orders**

Shipping is free on qualifying orders (default £60+). Exact threshold shown at checkout.

## Account

- Register / Login / Google Login
- Manage profile and addresses
- View reward points and store credit balances
- Read notifications

## Trade-in

1. Open **Trade-In**
2. Select console → device → model → storage → condition
3. Toggle accessories
4. See automatic **cash** vs **store credit** quote
5. Submit request and track status online

Store credit quotes are often higher than cash — check the on-screen comparison.

## Support

Use **Contact** or FAQ. Order emails come from the store noreply address.
